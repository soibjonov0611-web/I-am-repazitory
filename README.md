# Saipov_00 — Frontend Developer Portfolio

A modern, high-performance, dark premium portfolio website for **Saipov_00**, a passionate **Frontend Developer**. Built with React, Vite, Framer Motion, and a custom CSS design system featuring smooth glassmorphism, dynamic gradients, code editor hero section, and responsive layouts across all device screens.

---

## ✨ Main Features

- 🎨 **Dark Premium Aesthetics**: Custom glassmorphism cards, purple/cyan/blue gradient text, smooth hover effects, glowing backdrops, and interactive UI micro-animations.
- 💻 **Code Editor Hero**: Interactive code window displaying real-time developer configuration, floating technology badges, and quick social links.
- 🌐 **3-Language i18n System**: Native support for **🇺🇿 Uzbek** (default), **🇷🇺 Russian**, and **🇬🇧 English** with instant language switching and `localStorage` state persistence.
- 📱 **100% Fully Responsive Layout**: Tailored padding, fluid clamp typography, and zero horizontal scrollbar across viewports from **360px mobile to 1920px+ ultra-wide screens**.
- 🍔 **Mobile Navigation**: Glassmorphic mobile overlay menu with animated hamburger toggle and smooth auto-closing section links.
- ⚡ **Performance & Accessibility**: Optimized React architecture, subtle Framer Motion animations with `prefers-reduced-motion` support, and accessible ARIA attributes.
- 📬 **Interactive Contact Form & Socials**: Direct `mailto:` email dispatching and social chips linking to GitHub and Telegram.

---

## 🛠️ Tech Stack

- **Core**: React 19, HTML5, JavaScript (ES6+)
- **Build Tool**: Vite 8
- **Styling**: Vanilla CSS3 (CSS Variables, Flexbox, CSS Grid, `clamp()`, Glassmorphism)
- **Animations**: Framer Motion
- **Icons**: Lucide React & Custom SVG Brand Icons
- **i18n**: Custom React Context Provider with `localStorage` persistence

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18.0 or higher) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/soibjonov0611-web/saipov-portfolio.git
   cd saipov-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

### Development

To start the Vite development server locally:
```bash
npm run dev
```

### Production Build

To build the production bundle:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
